# AHKDeck third-party dependency list (ASCII ONLY - see the note below).
# Read by 2_download.bat: each active line is downloaded and extracted to
# .3rd/<name>/.
#
# ASCII-only note: cmd's "for /f" parses this file in the OEM code page;
# non-ASCII bytes (e.g. CJK comments) get mangled and can swallow the
# following "name=url" lines, silently skipping dependencies. Chinese notes
# live in build_readme.md / README.md.
#
# Format: name=url
#         name=url|marker-file
# The extracted top-level dir is renamed to "name" automatically. The optional
# "marker-file" (a path RELATIVE to .3rd/<name>/) is the integrity probe: the
# library counts as "already present" only if that file exists. This guards
# against a half-extracted directory left behind by an interrupted download.
#
# GitHub-hosted libraries use
#   https://codeload.github.com/<owner>/<repo>/tar.gz/<ref>
# instead of https://github.com/<owner>/<repo>/archive/<ref>.tar.gz - both
# serve the same archive, but codeload works through restrictive proxies where
# the archive/ path returns HTTP 502 (project lesson).
#
# Bump policy (m005): pin a commit or a tag, never a floating branch.
# Set AHKDECK_FORCE_DOWNLOAD=1 to ignore the presence checks and re-fetch
# everything from scratch.
